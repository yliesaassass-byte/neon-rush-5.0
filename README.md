# NEON RUSH v2
PWA mobile-first pour iPhone. Déployer les fichiers à la racine du dépôt GitHub Pages.
Fonctions : séances hebdomadaires, choix du nombre de séries par exercice avant la saisie, poids/répétitions enregistrés série par série, comparaison avec la séance précédente, conseils de séance, historique CSV, recherche nutrition avec FAQ intégrée.
La recherche nutrition utilise une petite base de réponses prédéfinies : ce n'est pas un assistant IA connecté à Internet. Les données sportives restent dans le stockage local du navigateur.\nVersion 2.1 : suivi journalier des quantités d'eau notées (repère visuel indicatif de 2 000 ml, non obligatoire) et journal personnel des repas. Pas de calcul calorique ou de quotas de macronutriments.\n\nVersion 2.2 : recherche de fiches aliments via l'API publique Open Food Facts (connexion Internet requise). Affiche les données disponibles : énergie, protéines, glucides, lipides, fibres, sucres, ingrédients et allergènes. La disponibilité et la complétude varient selon les fiches.\n

Version 2.3 : programme d'entraînement rééquilibré sur cinq jours : deux séances haut du corps, deux séances bas du corps et une séance cardio/mobilité. Conseils généraux : échauffement progressif, technique maîtrisée, charges adaptées, récupération et arrêt en cas de douleur. Pour les adolescents, privilégier l'encadrement d'un coach qualifié, éviter les tests de charge maximale et ne pas s'entraîner à l'échec.


Mise à jour du cache : le service worker utilise désormais neon-rush-v3 afin que les navigateurs récupèrent la nouvelle version après publication. Pour mettre à jour GitHub Pages, téléverser le CONTENU du dossier neon-rush à la racine du dépôt et valider le commit.
